# Ai-Expert · Эксперт ПД

Рабочее пространство для проверки проектной документации.

Ai-Expert помогает сверять сведения между документами, находить возможные расхождения и смотреть, на каких страницах основаны замечания. Результаты доступны в Telegram и приложении проекта.

[Открыть бота в Telegram](https://t.me/aiexpertproject_bot)

## Как это работает

```mermaid
flowchart LR
    A[Добавить документы проекта] --> B[Система читает поддерживаемые файлы]
    B --> C[Сверяет данные и требования]
    C --> D[Показывает замечания и ссылки на источники]
    D --> E[Специалист проверяет результат и решает, что делать дальше]
```

Проверка помогает быстрее ориентироваться в комплекте документов. Замечания можно проследить до источников, а итоговое решение остаётся за специалистом.

# PSD Bot

A practical workspace for reviewing project documentation.

PSD Bot helps a team compare information across project files, trace findings back to their source pages, and review results before making changes.

[Open the Telegram bot](https://t.me/aiexpertproject_bot)

## How it works

```mermaid
flowchart LR
    A[Send project documents] --> B[The system reads supported files]
    B --> C[Checks compare information across documents]
    C --> D[Review findings with links to source pages]
    D --> E[The team decides what to do]
```

The tool is designed to make document review easier to inspect: findings include their source, and a person remains responsible for reviewing them and deciding on next steps.
