# Устройство Ai-Expert

[На главную](../README.md)

Ai-Expert состоит из сервера обработки документов, Telegram-бота и веб-приложения. Это обзор существующей реализации; исходники приложения в этот репозиторий не включены.

## Основные части

| Часть | Ответственность |
| --- | --- |
| Telegram-бот | Приём файлов, выбор проекта, запуск проверки, вопросы и выдача результатов |
| Веб-приложение / Mini App | Документы, просмотр страниц, источники, реестр замечаний и работа команды |
| API на FastAPI | Запросы интерфейса, доступ к проектам и действия с документами |
| Обработка документов | Чтение поддерживаемых форматов, извлечение таблиц и распознавание сканов |
| Проверки | Числовая сверка, сопоставление сведений, нормативные источники и ИИ-анализ |
| Хранилище | Проекты, участники, версии документов, чтения страниц, результаты и статусы |
| Отчёты | Представление замечаний и источников в PDF и XLSX |

## Путь документа

1. Пользователь добавляет документ в проект. Оригинал сохраняется как версия файла.
2. Система читает страницы, текст и таблицы. Для сканов подключается OCR.
3. Проверка работает с зафиксированным составом комплекта и результатами чтения.
4. Числовые правила и ИИ-анализ формируют замечания. К ним прикрепляются источники и доступные координаты фрагментов.
5. Пользователь открывает замечание, смотрит исходные данные и принимает решение.
6. После изменений проводится новая проверка. Оригиналы и предыдущие версии остаются в истории.

## Почему проверки разделены

Разные задачи требуют разных способов проверки. Сумму значений в таблице можно проверить правилом. Поиск смыслового противоречия требует более широкого контекста. Разбор изображения страницы может подсказать проблему, но приблизительная оценка модели сама по себе не подтверждает точную геометрию.

Поэтому числовые проверки, распознавание, нормативный поиск и ИИ-анализ имеют отдельные этапы. Результат должен показывать, что удалось проверить и что осталось неподтверждённым.

## Источники и версии

Замечание связано с документом, его версией и страницей. Когда это возможно, сохраняются цитата и область на странице. Снимок комплекта фиксирует данные проверки, чтобы старый результат не начинал ссылаться на уже изменённое содержимое.

Ручные замечания сохраняются после повторных проверок. Их актуальность и закрытие подтверждает пользователь.

## Доступ и расходы

Доступ проверяется на уровне организации, участника и конкретного проекта. Пользователь работает с разрешёнными ему документами. Ключи внешних сервисов находятся на сервере.

Для платных запросов предусмотрены лимиты и учёт расходов. Вызовы внешних моделей зависят от настроенного маршрута; при таком вызове выбранные данные передаются провайдеру модели.
